# 🩸Blood Donation Management System

## About the Project
The Blood Donation Management System is a web-based application developed to manage blood donors and blood donation requests. 
It helps users register as donors and submit donation requests. The admin can view donor details and manage donation requests.

## Objectives
- To maintain donor information.
- To manage blood donation requests.
- To provide an easy-to-use web application.
- To help manage blood donation information efficiently.

## Features

### User Module
- User Registration
- User Login
- Donor Dashboard
- Create Blood Donation Requests
- Manage User Profile

### Admin Module
- Admin Login
- View Donor List
- View Donor Details
- View Donation Requests
- Update Request Status (Pending/Completed)

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** C#, ASP.NET Web Forms
- **Database:** Microsoft SQL Server
- **IDE:** Visual Studio
- **Database Tool:** SQL Server Management Studio (SSMS)

## Requirements
- Visual Studio
- .NET Framework compatible with the project
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Web browser

## ▶️ How to Run the Project

1. Clone or download this repository.
2. Open the project in Visual Studio.
3. Create the required database in SQL Server.
4. Execute the database SQL script, if included in the repository.
5. Update the database connection string in `Web.config`.
6. Build the project.
7. Run the application using Visual Studio.
